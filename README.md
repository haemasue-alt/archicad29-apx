# HaemaFinishSync for ARCHICAD

Windows x64 add-on releases for ARCHICAD 29 and 30.

- Download the APX matching your ARCHICAD major version from Releases.
- Register the APX in ARCHICAD Add-On Manager once.
- Use **DWG Finish Sync > 업데이트 확인...** for later updates.
- ARCHICAD must close normally before its loaded add-on can be replaced.

`updates/latest-ac29.json` and `updates/latest-ac30.json` are version-specific update feeds.
Each build has a separate release with its SHA-256 manifest. Validated builds from the developer PC are published automatically.

This repository distributes add-on binaries and release metadata. Project models and the proprietary ARCHICAD SDK are not included.
